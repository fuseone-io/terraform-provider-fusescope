# Generated code under internal/

Most of `internal/` was generated by `skaff` from the OpenAPI spec + `skaff.yml`. Generated files start with the `zz_generated_*` prefix, and the oapi-codegen client is marked `Code generated … DO NOT EDIT`.

`skaff` is private to SigNoz and not available to this fork, so the pipeline cannot be re-run. Until a replacement generator is chosen:

- Do not hand-edit generated files for a change the spec could express; record the needed spec or config change in an issue in `fuseone-io/terraform-provider-fusescope` instead.
- A hand-edit that cannot wait must say so in the PR, list every generated file touched, and keep the change minimal so a future regeneration can reproduce it.
- `skaff.yml` stays the declaration of every resource; keep it in sync with what the provider registers.

**Hand-written — safe to edit:**

- `internal/apiclients/{wrapped_client,doer,error}.go` — retry/auth/error HTTP wrapper
- `internal/convtypes/*.go` — generic conversion helpers (`StringPointer`, `TimeFromString`, …)
- `internal/provider/provider.go` — framework provider entry; registers each resource

When editing hand-written Go here, follow the `go-comments` and `go-newlines` rules.
